# Figure Chess

The web home for Figure Chess.

## Local preview

Serve the project root with any static HTTP server, for example:

```bash
npx serve .
```

## Deployment

The project is configured for Vercel. Commits to the connected GitHub repository deploy automatically.

## Xiangqi implementation plan

The current site is a static landing page. Playable Xiangqi, accounts, multiplayer, and ratings are planned in these documents:
